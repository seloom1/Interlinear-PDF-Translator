# أداة ترجمة ملفات PDF البينية (Interlinear PDF Translator) - الإصدار النهائي الشامل

أداة متخصصة لترجمة ملفات الكتب والمحاضرات الجامعية الطبية والعلمية بنظام الترجمة البينية (إنجليزي - عربي)، حيث توضع الترجمة العربية مباشرة فوق كل سطر إنجليزي بدقة طباعة عالية.

---

## 🌟 الميزات والمواصفات الأساسية

1. **تغطية شاملة بنسبة 100% (بدون سقوط أي سطر):**
   - اعتماد نظام الترقيم التزامني الفائق (`Indexed Delimiters`) لضمان ترجمة كل سطر إنجليزي بشكل مباشر ودقيق دون أي حذف أو تجاهل لأي سطر في الفقرات الطويلة.

2. **🟢 تظليل الكلمات الطبية حصراً بالأخضر الزمردي (Word-Level Medical Detection):**
   - معجم طبي ضخم يشمل مئات المصطلحات التخصصية للأحياء الدقيقة (`Microbiology`)، وعلم الخلية (`Cytology`)، والجينات (`Genetics`)، والتشريح، والقلب، والأعصاب، والأورام.
   - تلوين الكلمة الطبية التخصصية فقط باللون الأخضر المميز مع شريط خلفي ناعم، بينما تظل الكلمات العادية وحروف الجر والأفعال باللون الطبيعي المختار (مثل الأزرق الملكي).
   - قائمة استبعاد صارمة (`NEVER_MEDICAL`) لمنع تظليل مصطلحات الكيمياء مثل `كلوريد` أو أفعال مثل `استخدم` بالخطأ.

3. **تحكم دقيق وفوري بحجم الخط:**
   - تطبيق حجم الخط المختار في الواجهة (مثل 5.5، 6.5، 7.5، 8.5 pt) حرفياً دون أي تقليص إجباري.

4. **توجيه عربي طبيعي ومحاذاة مريحة:**
   - قراءة من اليمين إلى اليسار (RTL) بطباعة عربية سليمة.
   - محاذاة متوازنة مائلة قليلاً نحو اليمين (`Balanced Right`) فوق السطر الإنجليزي.

5. **دعم الصفحات المصورة وغير القابلة للتحديد عبر الذكاء الاصطناعي (OCR):**
   - فحص واستخراج فوري للنصوص من الصفحات الممسوحة ضوئياً والمخططات عبر محرك RapidOCR.

## 🚀 طرق التشغيل المباشر

### 1. تشغيل الواجهة الرسومية (GUI):
- انقر نقراً مزدوجاً على ملف: **`تشغيل_مباشر.vbs`** (يعمل بصمت بدون ظهور نافذة سوداء).
- أو عبر ملف: **`تشغيل_أداة_الترجمة.bat`**.

### 2. سطر الأوامر (CLI):
```bash
python cli.py "lecture.pdf" -o "lecture_translated.pdf" -s 6.5
```
- `-s` أو `--size`: حجم الخط (مثلاً: 6.0 أو 6.5 أو 7.0).
- `-c` أو `--color`: لون النص الأساسي (`blue`, `red`, `slate`, `green`, `black`).
- `--no-medical`: إلغاء التظليل الأخضر للمصطلحات الطبية.
- `-p` أو `--pages`: تحديد نطاق صفحات محدد (مثال: `1-5` أو `1,3,7`).

## 📦 متطلبات التشغيل

تثبيت المكتبات المطلوبة (إذا لم تكن مثبتة مسبقاً):
```bash
pip install -r requirements.txt
```
المكتبات المستخدمة:
- `pymupdf` (معالجة وقراءة ملفات PDF)
- `PySide6` (الواجهة الرسومية الحديثة)
- `rapidocr-onnxruntime` (التعرف الضوئي على النصوص OCR)
- `arabic-reshaper` و `python-bidi` (تشكيل النصوص العربية RTL)
- `requests` (الاتصال السحابي للترجمة)
